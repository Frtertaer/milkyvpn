# KAL/2 — протокол

KAL/2 — протокол Mirage core: TLS/h2-маскирующий транспорт с
мультиплексированными потоками для обхода DPI/цензуры.

**Документы:**

| файл | содержание |
|------|-----------|
| `SPEC.md` | полная спецификация провода: carriers, рукопожатие, записи, мультиплекс, UDP, эгресс-политика |
| `THREAT_MODEL.md` | модель угроз: что защищаем, ограничения, механизмы |
| `DESIGN.md` | архитектура Mirage core (копия из репозитория ядра) |
| `CONSUMING.md` | как встроить ядро в своё приложение (Go API, JNI-контракт, JSON-конфиг) |

**Эталонная реализация** — `Frtertaer/milkyvpn/milky-core` (ветка
`devin/1790199091-kal2-universal-subscriptions`), Go 1.23+.

**Готовое приложение** (Android/ПК, использует KAL/2) — ветка
`milky-app` этого же репозитория / готовый APK в `dist/`.

Версия протокола на проводе: `Version = 2`, magic `KLDO-in-`.
