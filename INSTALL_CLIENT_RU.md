# Установка клиента KAL/2 — по шагам (для чайника)

Нужно: файл `kal2-client-windows-x64.exe` (для Windows) или
`kal2-client-linux-x64` (для Linux) из папки `dist/`, и 4 параметра
подключения, которые вам выдал владелец сервера:

| параметр | как выглядит | где взять |
|----------|--------------|-----------|
| адрес сервера | `123.45.67.89:443` | выдал владелец |
| SNI (домен) | `kal.example.dev` | выдал владелец |
| pub-ключ | 64 символа hex | `kal2-server -keygen` на сервере, строка `pub:` |
| ваш PSK | 64 символа hex | владелец создал для вас |

## Шаг 1. Скачайте клиент

- Windows: `dist/kal2-client-windows-x64.exe` → сохраните куда угодно
  (например, `C:\kal2\kal2-client.exe`).
- Linux: `dist/kal2-client-linux-x64` → `chmod +x`.

## Шаг 2. Запустите

Откройте «Командную строку» (Win+R → `cmd`) и выполните одной строкой:

```
C:\kal2\kal2-client.exe -addr 123.45.67.89:443 -sni kal.example.dev -pub <64-символа-pub> -psk <ваш-64-символа-psk> -drift /api/v2/stream -carrier auto -socks 127.0.0.1:10808
```

Если увидели `kal2: session up via auto` и `kal2: socks5 on 127.0.0.1:10808` —
работает. Окно не закрывайте — пока оно открыто, VPN жив.

## Шаг 3. Направьте программы в туннель

Вариант А — браузер (проще всего проверить):

- Firefox: Настройки → Сеть → Ручная настройка прокси → SOCKS5:
  `127.0.0.1`, порт `10808`, галка «Проксировать DNS через SOCKS5».
- Chrome/Edge: удобнее через расширение (например, ZeroOmega/SwitchyOmega)
  — тип SOCKS5, хост `127.0.0.1`, порт `10808`.

Вариант Б — весь ПК (системный SOCKS): Windows не умеет SOCKS глобально —
используйте любой SOCKS-capable клиент (v2rayN/Nekoray в режиме
«external SOCKS») и укажите `127.0.0.1:10808` как выход.

## Проверка

Откройте https://ifconfig.me — должен показать IP вашего сервера, а не ваш.
Или в другой строке cmd:

```
kal2-client.exe <те же флаги> -fetch https://api.ipify.org?format=json
```

Выведет `{"ip":"<ip-сервера>"}` — туннель в порядке.

## Если не поднимается

1. `session up` не появляется — проверьте, нет ли опечатки в pub/psk
   (ровно 64 символа), и пингуется ли IP сервера.
2. Поднимается, но сайты не открываются — проверьте, что прокси стоит
   именно SOCKS5 (не HTTP) и порт 10808.
3. `-carrier drift` — попробуйте, если veil блокируется; `auto` сам выберет
   живой путь.

## Дополнительные флаги

| флаг | для чего |
|------|----------|
| `-addr a,b,c` | несколько входов (IP сервера, релей, CDN) — ротация при обрыве |
| `-proxy http://u:p@h:port` | выходить через HTTP-прокси (например, корпоративный) |
| `-fetch URL` | разовая проверка без SOCKS |
| `-fetchmax N` | лимит чтения для -fetch (по умолчанию 32 МБ) |
