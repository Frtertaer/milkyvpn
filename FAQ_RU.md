# MilkyVPN — частые вопросы

## Установка и обновление

**Какую APK ставить на Android?**
`arm64-v8a` — почти все телефоны с 2016 года. `armeabi-v7a` — старые 32-битные. `x86_64` — эмуляторы.

**Приложение само обновляется?**
Да, начиная с v1.1.0: проверка при запуске + кнопка в настройках. Устанавливает из GitHub Releases, одно подтверждение системой.

**Обновление просит снести старую версию?**
Значит старый билд был дебажно-подписан (всё до v1.2.0): подписи не совпадают. Экспортируй профили (список ссылок) перед сносом — хранилище сотрётся вместе с приложением.

## Подключение

**Профили на одном хосте :443 — чем они отличаются?**
Это разные карьеры (veil/cdn/mosaic) и фронты — смотри чип справа в строке профиля: `carrier · front-хост`.

**Какой профиль выбрать?**
Строка «Авто (самый быстрый)» вверху списка — приложение измеряет задержку до каждой точки входа и ставит самую быструю. Чип `udp` у профиля = UDP-карьер, задержку мерить по TCP нельзя, но он не «мёртв».

**Вайфай ↔ LTE — туннель рвётся?**
Нет: сессия мигрирует без разрыва (resumption v2.1 включён на сервере). Короткая пауза возможна, переподключения нет.

**VPN поднят, а сайт «видит» мой реальный IP?**
Проверь «DNS и утечки» в настройках: Private DNS в режиме «hostname» ходит мимо туннеля на Android — там же видно, открывается ли DoH через туннель.

## Трафик и скорость

**Можно пустить через VPN не всё?**
Настройки → «Приложения через VPN» (Android): только выбранные / все, кроме выбранных.

**Как померить скорость?**
Настройки → «Скорость» — меряет через живой туннель (ping + Mbps).

**Windows: браузер работает, а игра — нет?**
Включи «Полный туннель» в настройках — wintun-адаптер маршрутизирует весь трафик, не только приложения с поддержкой прокси. Один UAC-запрос на подключение.

## Приватность

**Что пишется в лог?**
Только таймстемпы, байты и user-id — никаких адресов сайтов, DNS-имён или содержимого. Аудит-лог панели — только действия администратора.

**Куда деваются мои ссылки?**
Подписка (`/sub/<token>`) отдаёт актуальные ссылки по HTTPS; авто-обновление можно выключить в панели — клиенты останутся на своих профилях.

## Панель администратора

**Как включить 2FA?**
Администрирование → «Включить 2FA» → сканируй QR в Google Authenticator/Aegis → введи код. Дальше вход = токен + код.

**Потерял код 2FA — как войти?**
На сервере: убери поле `totp_secret` из `/etc/kal2/panel.json` и `systemctl restart kal2-panel`.

**Как перенести канарейку на новый RU-сервер?**
`deploy/canary-bootstrap.sh <новый-хост>` с машины, где лежит ops-ключ — скрипт ставит пробник, cron и проверяет прогон.

## Если не работает

| Симптом | Что проверить |
|---|---|
| «Все входы мёртвы» | Панель → карточка «Входы живы из РФ» — если красная, проблема на сервере/канале, не у тебя |
| Подключено, трафик не идёт | Подожди до ~90 с (переустановка сессии), затем другой карьер |
| Приложение падает при Connect | Настройки → диагностика → санитизированный лог — приложи к issue |
| Подписка не обновляется | Авто-обновление выключено в панели (404 — это оно) |
