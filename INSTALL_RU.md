# Milky VPN — установка (простая, для всех)

## Windows (ПК)

1. Скачайте файл `MilkyVPN-Setup.exe`.
2. Запустите его двойным кликом. Если Windows покажет «Фильтр SmartScreen» —
   нажмите **Подробнее** → **Выполнить в любом случае**.
3. Нажмите **Далее** → **Установить** → **Готово**. Права администратора не нужны —
   приложение ставится в вашу папку.
4. Откройте **Milky VPN** (ярлык на рабочем столе или в меню Пуск).

## Android (телефон)

1. Скачайте файл `app-debug.apk` на телефон (или перекиньте с компьютера).
2. Откройте его — телефон спросит разрешение «установка из неизвестных
   источников»: разрешите один раз для браузера/файлового менеджера.
3. Нажмите **Установить** → **Открыть**.

## Первый запуск: подключаем подписку

1. В приложении нажмите **Импорт** (экран приветствия или «+»).
2. Вставьте ссылку на подписку (например `https://sub.milky.homes/s/...`)
   или любую ссылку вида `vless://`, `vmess://`, `trojan://`, `ss://`,
   `hysteria2://`, `kal2://` — подойдёт всё: публичные https-подписки
   и одиночные ссылки.
3. Нажмите **Импортировать** → выберите профиль в списке → **Подключиться**.

Подсказка: если есть текст с несколькими ссылками сразу (шапка подписки) —
вставляйте как есть, приложение само разберёт совместимые профили.

## Если подписка не открывается

- Проверьте, что ссылка начинается с `https://` (локальные адреса —
  `localhost`, `192.168.x.x` — отклоняются по безопасности).
- Скопируйте ссылку целиком, без пробелов по краям.
- Приложение покажет, сколько профилей распознано и сколько совместимо —
  несовместимые подсвечены причиной.

## Что внутри (коротко)

KAL/2 — собственный протокол: настоящий TLS 1.3 + сайт-обманка,
двойной транспорт (veil+drift) с параллельным дозвоном и автоподъёмом —
для DPI это обычный HTTPS к обычному сайту.
