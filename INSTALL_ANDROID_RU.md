# Установка Milky VPN на телефон — по шагам (для чайника)

## Шаг 1. Скачайте APK на телефон

Откройте на телефоне эту страницу GitHub, зайдите в `dist/` и нажмите на
файл `milky-arm64-v8a.apk` → «Download» (или «View raw»). Скачается в
папку «Загрузки».

Если при установке напишет «несовместимо» — качайте `milky-armeabi-v7a.apk`
(для старых телефонов, включая Android 6).

## Шаг 2. Разрешите установку

Android спросит: «Установка из неизвестных источников». Разрешите —
это стандартное предупреждение для любого APK не из Play Market.

- На новых Android: нажмите на скачанный файл → «Настройки» →
  «Разрешить из этого источника» → назад → «Установить».
- На Android 6–8: Настройки → Безопасность → «Неизвестные источники» — включить.

## Шаг 3. Откройте приложение и вставьте профиль

1. Запустите Milky VPN (иконка в меню).
2. Получите у владельца сервера ссылку-профиль вида `kal2://...`
   (одна строка — можно переслать в мессенджер себе).
3. В приложении: экран «Подписка/Импорт» → вставьте ссылку → сохраните.
4. Выберите профиль в списке → большая кнопка «Подключить».
5. Android спросит разрешение на VPN — нажмите «ОК». В шторке появится
   ключик — туннель поднят.

## Шаг 4. Проверьте

Откройте в браузере телефона `ifconfig.me` — должен показаться IP
сервера, а не вашего оператора.

## Если не работает

- «Подключить» серое/ошибка — проверьте, что ссылка вставлена целиком
  (без пробелов по краям) и сервер жив (попросите владельца проверить).
- VPN поднимается, но сайты не открываются — в настройках профиля
  смените carrier на `drift` или `auto`.
- Батарея жалуется — Android убивает фоновую службу: Настройки →
  Приложения → Milky VPN → «Без ограничений» по батарее.

## Удалить

Настройки → Приложения → Milky VPN → Удалить. Профили (ключи) хранятся
только в защищённом хранилище телефона и удаляются вместе с приложением.
