# Milky VPN на ПК (Windows) — по шагам (для чайника)

Есть два способа: **обычное приложение с установщиком** (рекомендуется)
и **консольный клиент** (для продвинутых и для проверки протокола
из командной строки).

---

## Способ 1 — приложение с установщиком

### Шаг 1. Скачайте и запустите установщик

`MilkyVPN-Setup.exe` — скачайте, двойной клик, подтвердите установку.
Установщик сам разложит файлы в `AppData\Local\MilkyVPN` и положит
ярлык **Milky_VPN** на рабочий стол и в меню «Пуск».

### Шаг 2. Импортируйте профиль

Откройте приложение → «Добавить подписку» → вставьте `kal2://...`
ссылку, которую вам дал владелец сервера → «Добавить».

### Шаг 3. Подключитесь

Выберите профиль → большая кнопка «Подключиться». Приложение само
запустит встроенное ядро kal2 (файл `kal2\kal2-client.exe` рядом с
программой) и включит системный прокси `SOCKS5 127.0.0.1:11808` —
браузеры и большинство программ пойдут через туннель сразу.

Кнопка «Отключиться» возвращает прокси как было.

### Полный туннель (весь трафик ПК, не только браузер)

«Настройки» → включите «Полный туннель». При подключении Windows один раз
спросит права администратора (UAC) — разрешите: приложение поднимет
виртуальный адаптер MilkyVPN-TUN и заведёт ВЕСЬ трафик компьютера
(игры, мессенджеры, обновления) через VPN. Выключите — и всё вернётся
к обычному прокси-режиму.

### Проверка

Откройте `ifconfig.me` в браузере — должен показаться IP сервера
(второй конец туннеля), а не ваш домашний.

### Если не поднимается

- «core_missing» — переустановите через Setup (ядро не доложилось).
- «connect_timeout» — провайдер режет veil; в ссылке профиля
  `carrier=drift` вместо `veil`, или попросите вторую ссылку.
- Антивирус ругается на kal2-client.exe — разрешите файл (консольная
  программа без цифровой подписи).

### Удаление

«Параметры → Приложения → Milky VPN → Удалить» — либо запустите
`unins000.exe` в папке `AppData\Local\MilkyVPN`. Ярлыки и запись
в реестре убираются сами.

## Способ 2 — консольный клиент (продвинутый)

`kal2-client-windows-x64.exe` поднимает локальный SOCKS5-прокси.

### Шаг 1. Скачайте клиент

`dist/kal2-client-windows-x64.exe` → сохраните, например, в
`C:\kal2\kal2-client.exe`.

### Шаг 2. Запустите

Win+R → `cmd` → одной строкой (параметры даёт владелец сервера):

```
kal2-client.exe -addr <сервер>:443 -sni <sni> -pub <64-символа> -psk <64-символа> -drift /api/v2/stream -carrier auto -socks 127.0.0.1:10808
```

Строки `kal2: session up via auto` и `kal2: socks5 on 127.0.0.1:10808` —
туннель жив, окно не закрывайте (можно свернуть).

### Шаг 3. Браузер в туннель

**Firefox**: Настройки → «Параметры сети» → Ручная настройка →
SOCKS5 `127.0.0.1:10808`, «Проксировать DNS» → ОК → `ifconfig.me`.

**Chrome/Edge**: расширение ZeroOmega/SwitchyOmega → профиль
SOCKS5 `127.0.0.1:10808` → включить.

### Быстрая проверка без браузера

```
kal2-client.exe <те же флаги> -fetch https://api.ipify.org?format=json
```

`{"ip":"<ip-сервера>"}` — туннель работает.
