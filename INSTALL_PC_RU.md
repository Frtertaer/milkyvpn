# Milky VPN на ПК (Windows) — по шагам (для чайника)

Для ПК используется консольный клиент `kal2-client` — он поднимает
локальный SOCKS5-прокси `127.0.0.1:10808`, через который идёт весь
туннельный трафик.

## Шаг 1. Скачайте клиент

`dist/kal2-client-windows-x64.exe` → сохраните, например, в
`C:\kal2\kal2-client.exe`.

## Шаг 2. Узнайте параметры подключения

У владельца сервера возьмите одну команду целиком — она выглядит так
(параметры подставлены его):

```
kal2-client.exe -addr 23.133.88.167:443 -sni kal.mergescribe.dev -pub <64-символа> -psk <64-символа> -drift /api/v2/stream -carrier auto -socks 127.0.0.1:10808
```

## Шаг 3. Запустите

Win+R → `cmd` → вставьте строку из шага 2 → Enter.

Должны появиться строки `kal2: session up via auto` и
`kal2: socks5 on 127.0.0.1:10808`. Окно НЕ закрывайте — пока оно
открыто, туннель жив. Свернуть можно.

## Шаг 4. Направьте браузер в туннель

**Firefox** (проще всего):
Настройки → внизу «Параметры сети» → Ручная настройка → SOCKS5:
`127.0.0.1`, порт `10808`, включите «Проксировать DNS через SOCKS5 v5» →
ОК. Откройте `ifconfig.me` — покажет IP сервера.

**Chrome/Edge** — системный прокси Windows SOCKS не понимает напрямую;
проще всего поставить расширение (ZeroOmega/SwitchyOmega) и создать
профиль SOCKS5 `127.0.0.1:10808`, включить его.

## Шаг 5. Весь ПК через туннель (опционально)

Windows сама SOCKS глобально не проксирует. Два рабочих варианта:

- **v2rayN / Nekoray** — добавьте «SOCKS-сервер» `127.0.0.1:10808` как
  выходной сервер и включите системный прокси/TUN.
- **Proxifier** — правило: все приложения → SOCKS5 `127.0.0.1:10808`.

## Быстрая проверка без настройки браузера

```
kal2-client.exe <те же флаги> -fetch https://api.ipify.org?format=json
```

Вывод `{"ip":"<ip-сервера>"}` — туннель работает.

## Если не поднимается

- Нет `session up` — проверьте, что команда скопирована ЦЕЛИКОМ в одну
  строку, без переносов; pub/psk ровно 64 символа.
- Провайдер режет veil — попробуйте `-carrier drift`.
- Антивирус блокирует exe — разрешите файл (это просто консольная
  программа, цифровой подписи нет).

## Автозапуск (по желанию)

Создайте ярлык на `kal2-client.exe` с параметрами из шага 2 и положите
его в `Win+R → shell:startup` — клиент будет подниматься при входе
в Windows.
