## 1. Кратко

MilkyVPN — клиент VPN, который подключает ваше устройство к серверам вашей подписки. Приложение:

- **не содержит** аналитики, рекламы, трекеров и сторонних SDK сбора данных;
- **не ведёт журналов** посещённых сайтов, DNS-запросов или содержимого трафика;
- **не требует** учётной записи, e-mail или номера телефона;
- **не передаёт** данные никаким третьим лицам, кроме серверов подписки, которые вы сами добавили.

## 2. Какие данные обрабатываются

| Данные | Где хранятся | Зачем | Покидают ли устройство |
|---|---|---|---|
| Ссылка на подписку (`https://sub.milky.homes/s/…`) | Только на устройстве, в зашифрованном хранилище (Android Keystore) | Получение списка серверов | Да — только к `sub.milky.homes` по HTTPS |
| Параметры серверов (адрес, порт, ключи доступа) | Только на устройстве, в зашифрованном хранилище; исключены из резервных копий | Установка VPN-соединения | Да — только к выбранному VPN-серверу |
| Настройки (тема, автоподключение, выбранный регион) | Только на устройстве | Работа интерфейса | Нет |
| Диагностика (версия приложения, версия Android, состояние соединения, класс ошибки) | Формируется по запросу, не сохраняется | Помощь службе поддержки | Только если вы сами скопируете и отправите её |

Диагностика **автоматически удаляет** секреты: токены подписки, идентификаторы пользователей, ключи и пароли заменяются на `••••••`.

## 3. Сетевой трафик

При активном VPN весь трафик устройства (кроме самого приложения MilkyVPN, чтобы исключить петлю маршрутизации) направляется через зашифрованный туннель к VPN-серверу из вашей подписки. Приложение не анализирует, не фильтрует и не сохраняет этот трафик. DNS-запросы внутри туннеля направляются через VPN-сервер.

Обработка трафика на стороне VPN-серверов регулируется политикой оператора серверов вашей подписки.

## 4. Разрешения Android

- **VPN (BIND_VPN_SERVICE)** — создание туннеля; запрашивается системным диалогом Android при первом подключении.
- **INTERNET** — доступ к серверам подписки и VPN.
- **FOREGROUND_SERVICE / FOREGROUND_SERVICE_SPECIAL_USE** — поддержание соединения в фоне с постоянным уведомлением.
- **POST_NOTIFICATIONS** — уведомление о состоянии VPN.
- **ACCESS_NETWORK_STATE** — обнаружение смены сети (Wi‑Fi ↔ мобильная).

Приложение не запрашивает доступ к местоположению, контактам, камере, файлам, микрофону.

## 5. Хранение и удаление

Все данные хранятся локально. Резервное копирование данных приложения в Google отключено (`allowBackup=false`, правила исключения для Android 12+). Удалить данные можно кнопкой «Удалить подписку» в приложении или удалением приложения.
